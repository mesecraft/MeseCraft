# Radioactive gas

Mese ore exposed to the vacuum of space slowly gives off a green gas. The gas
can't be breathed and does a little damage, and it disappears when it touches
air.

Rewritten for MeseCraft, with a new texture, replacing an earlier radioactive
gas mod from the Pandorabox server that had no license. Code and texture are
AGPLv3, like the rest of MeseCraft.
